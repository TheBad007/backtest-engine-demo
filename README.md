# Мини бэктест-движок с инвариантами честности

Компактный (один файл, ~150 строк), но настоящий движок для проверки торговых
стратегий на часовых барах. Его главная ценность — не стратегия, а **тесты-инварианты**:
14 автотестов, каждый из которых ловит отдельный класс багов, из-за которых
бэктесты врут (а затем «врут» и реальная торговля).

## Почему это важно

Типовой открытый бот при независимой проверке теряет деньги. Причины почти
всегда одни и те же:

- **знак funding перепутан** — классический баг `copysign(1, frac) * frac = |frac|`,
  когда *обе* стороны сделки платят funding (или обе получают);
- **lookahead** — сигнал на баре t рассчитан по ценам бара t+1, стратегия
  «видит будущее» и показывает доходность, которой нет;
- **нет capacity** — тест на объёме 1000 BTC/бар, а рынок принял бы 5%;
- **биты данные молча интерполируются** — пропуск цены заменяется соседним
  значением, и прогон «успешно» проходит по выдуманным данным.

Каждому классу бага здесь соответствует тест, который его ловит.

## Инварианты (по одному тесту на каждый)

| # | Инвариант | Тест |
|---|-----------|------|
| 1 | Консервация: финальный капитал пересчитывается из лога сделок независимо от движка | `test_conservation_after_roundtrip`, `test_independent_pnl_recompute` |
| 2 | Funding платит только держатель; long при rate>0 платит, при rate<0 получает | `test_funding_sign_long_pays_when_positive`, `test_funding_negative_rate_long_receives` |
| 3 | Нет lookahead: сигнал на баре t исполняется строго по open(t+1); сдвиг данных меняет результат | `test_signal_at_t_executes_at_t_plus_1`, `test_no_lookahead_shifted_data_degrades` |
| 4 | Fail-closed: NaN/нулевые/пропущенные данные останавливают прогон | `test_nan_close_fails_closed`, `test_zero_volume_fails_closed`, `test_empty_bars_fails_closed` |
| 5 | Capacity: заявка больше 5% объёма бара урезается, клип логируется | `test_capacity_clip_limits_size` |
| 6 | Prereg: критерий зафиксирован до запуска — на заведомо проигрышном рынке убыток не «смягчается» | `test_prereg_style_no_soft_pass` |
| 7 | Funding начисляется только в позиции и только в интервале | `test_funding_only_when_holding` |

## Как движок защищён от lookahead

```
бар t-1        бар t                бар t+1
  |              |                     |
  |   сигнал считается по данным <= t   |
  |              |---- сделка по open(t+1) ---->
```

Сигнал SMA-cross вычисляется только по закрытиям баров ≤ t. Сделка исполняется
на **следующем** баре по его цене открытия. Ни одна цифра бара t+1 не участвует
ни в сигнале, ни в цене исполнения.

## Формула funding (знак — главное)

```python
pay = abs(funding_rate) * notional        # величина платежа
sign = +1.0 if funding_rate >= 0 else -1.0
cash -= sign * pay                        # long платит при rate>0, получает при rate<0
```

Тест `test_funding_sign_long_pays_when_positive` проверяет и знак, и величину:
`abs(amount) == funding_rate * notional` до 1e-12.

## Запуск

```bash
python -m pytest test_engine.py -v     # 14 passed
```

Зависимостей нет — только стандартная библиотека и pytest.

## Формат работ

- **аудит** вашего бэктеста: прогон этого набора проверок, отчёт со списком багов;
- **разработка** движка с нуля по этому стандарту (реальные данные, перпетуалы, плечо).

Методология обкатана на реальных данных Binance/Deribit за 2020–2026.
